# Kids Math Games

Free, playful browser games for teaching young kids math concepts. No install, no build step — just static HTML pages, live on GitHub Pages.

**Play now:** https://youyangh.github.io/kids-math-games/

## Games

### 🔢 Square Number Adventure
`/square-number-adventure/`

Tap-to-count game exploring square numbers (1×1 through 10×10). Includes a Quiz Time mode with two-choice questions, spoken numbers, and a per-number character/emoji theme.

## Adding a new game

1. Create a new folder at the repo root (e.g. `/addition-race/`) with a self-contained `index.html`.
2. Add a card for it in the root `index.html` landing page.
3. Commit and push — GitHub Pages picks it up automatically.
